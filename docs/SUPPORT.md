> Crypto contributions are voluntary support for the open-source project. They do **not** purchase CodeCortex Cloud, Team, Enterprise, support SLAs, ownership, equity, tokens, or guaranteed roadmap influence.

## Important before sending

- Send only the asset shown for the exact network shown.
- Do **not** send funds to a token contract address.
- Crypto transfers are generally irreversible.
- Verify the complete destination address before confirming a transfer.
- A wallet, exchange, or custodian can apply its own minimum deposit and confirmation requirements. Check the current requirements before sending.
- If you are unsure about the network, do not send until you have verified it.

## قبل از ارسال

- فقط همان ارز را روی همان شبکه‌ای که مشخص شده ارسال کنید.
- وجه را به Contract Address توکن ارسال نکنید.
- تراکنش‌های کریپتو معمولاً قابل برگشت نیستند.
- قبل از تأیید، کل آدرس مقصد را دوباره بررسی کنید.
- کیف پول یا صرافی می‌تواند حداقل واریز و تعداد تأییدهای مخصوص خود را داشته باشد. قبل از ارسال، شرایط فعلی را بررسی کنید.
