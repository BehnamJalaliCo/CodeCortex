# CodeCortex Cloud and Enterprise Early Access

CodeCortex Community remains the open-source foundation. Core local workflows are not being moved behind a paywall.

This page describes planned hosted and organization features. It is an early-access roadmap, not a service-level commitment.

## Community

**$0 open-source core**

- CLI and MCP
- local repository indexing
- search and context retrieval
- impact analysis
- local project workflows

## Cloud Pro

Planned for individuals who want CodeCortex without managing the service layer.

Expected scope:

- managed setup and upgrades
- cloud workspace synchronization
- durable hosted workspace state
- usage and activity history

## Team

Planned for software and AI teams.

Expected scope:

- multiple users and repositories
- shared project and team memory
- team dashboard
- workspace and member administration
- shared operational history

## Enterprise

Planned for organizations with security, governance, and deployment requirements.

Expected scope:

- SSO and SAML
- role-based access control
- audit logs and retention controls
- private or controlled deployment
- service-level and support options
- enterprise policy and administration

## Join early access

Open the [Cloud / Enterprise early-access issue](https://github.com/BehnamJalaliCo/CodeCortex/issues/new?template=cloud-enterprise-interest.yml).

The issue is public. Do not post secrets, proprietary repository details, customer data, security findings, or personal information.

For a confidential enterprise evaluation, contact the maintainer through the GitHub profile until a private intake channel is available.

## Product principle

Paid plans are intended to sell operational convenience, hosting, collaboration, governance, and support. They are not intended to remove the useful Community core that drives adoption.
